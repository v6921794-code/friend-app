# Friend

Friend is an adult-only random communication platform with text chat and WebRTC video/audio.

## Features

- 18+ account registration
- Login and logout
- Profile and bio
- Settings
- Password change
- Random friend matching
- Text chat
- WebRTC video/audio
- Microphone control
- Camera control
- Next friend
- Stop
- Report
- Block
- Admin report panel
- PWA support
- Security headers
- Rate limiting
- Password hashing
- JWT authentication

## Run locally

```bash
npm install
node server.js
